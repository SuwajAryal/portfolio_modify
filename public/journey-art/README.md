# Selected explorer scenes

Original, owner-selected AI-generated pixel-art scenes: Himalayas, hills, Terai.
Selected for integration on 26 October 2026, with slightly fairer face/hand tones.
The avatar is a stylized stand-in, not a portrait. Four frames per GIF, 350 ms
per frame, 48-colour palette. PNG files provide still frames for pause mode and
reduced-motion preferences. Scenery is illustrative and has no survey accuracy.
Terai was extended into a portrait composition to match the other scenes:
384×480 pixels, with more river and flat banks and irregular navy outer edges.
See the repository SOURCES.md for production and provenance notes.
